# Nexus Digital Wallet Dashboard

**Live Demo:** https://sovanna-nexus-digital-wallet.netlify.app/

A responsive React + TypeScript dashboard simulating a digital banking/wallet app, inspired by ABA Bank's clean mobile design.

Built as a portfolio piece to demonstrate:
- Modern React (Vite) + TypeScript
- SASS modular styling with custom theme
- Realistic financial data handling (multi-currency, transactions)
- Interactive features: search, category filter, sort, pagination
- Performance & accessibility focus
- Professional setup & documentation

## Tech Stack
- React 18 + TypeScript
- Vite (fast dev server & build)
- SASS (modular + variables)
- Mock data (no backend)

## Features
- Account balances (USD + KHR) with fade-in animation
- Transaction list with search by description
- Category filter dropdown
- Newest-first sorting
- Load-more pagination
- Empty state handling
- Responsive layout
- Clean console & high Lighthouse scores
